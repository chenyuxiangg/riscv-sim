1 功能概述

1.1 模块定位

M-03 视图状态管理（View Store）（4.1.3）：前端交互层状态管理层。维护各视图独立状态并保证切换后状态保持（V-11）；订阅 S1/W1/T1/E1 流并按节流合并，向视图组件提供一致的只读状态快照。断线重连后经 M-07 序列号续拉并对账（reconcile）。订阅合并边界纳入调用链轻量打点（进入/离开耗时采样），仅管理员通道可见（评审 P-20）。

MVP 实现范围：channelState（S1/W1/T1/E1 通道状态全局单例，03-5）+ storeMap（视图私有状态）、subscription（通道订阅 + 节流/直通规则）、throttleTimer（≤200ms 合并节流，leading/trailing）、mergeSpan（合并耗时采样，P-20）；getState/applyDelta/subscribe·unsubscribe/reconcile 四函数闭环（表24）。

2.1.1 复杂结构字段定义

数据模型两态分离（03-5 重构）：channelState 为 S1/W1/T1/E1 通道状态全局单例（applyDelta 合并落此，多视图共享引用）；storeMap 仅存视图私有状态（UI 过滤/展开/缓存，切换保持 V-11）；getState 按 ViewComponent.channels 子集订阅、输出**平铺 StoreState**（6 字段，未订阅通道字段为空态对象）交付 M-02 render（M-02 v1.4 消费结构一致，03-9 双侧对齐）；视图私有态仅内部对账锚点，不进交付结构（N26 修复）；mergeSpan 环形采样仅管理员通道可见（P-20）。字段定义如下：

// StoreState: getState 输出的完整视图状态（M-03 输出契约；M-02 render 消费，03-9 双侧对齐）
struct StoreState {
  uint64_t timeVirt;            // 虚拟时间（权威源 M-12，按事件推进）
  uint32_t version;             // 状态版本（按虚拟时间戳单调递增，4.1.3.5 冲突以新者为准）
  SimState sim;                 // S1 仿真状态（寄存器/内存/PC/断点）
  WaveformState wave;           // W1 波形数据（通道/时间轴）
  TerminalState term;           // T1 串口回显缓冲
  EventState events;            // E1 事件（breakpointHit/trap/paused）
};
// ChannelState: 通道状态全局单例（03-5；每通道一份，多视图共享引用）
struct ChannelState {
  SimState sim; WaveformState wave; TerminalState term; EventState events;
};
// ViewPrivateState: 视图私有状态（storeMap 值；UI 过滤/展开/缓存；切换保持 V-11；
//   仅 M-03 内部使用（对账锚点），不进入 getState 交付结构——M-02 渲染消费平铺 StoreState（N26 修复））
struct ViewPrivateState {
  uint32_t uiFlags;             // UI 过滤/展开/选中等本地态（M-02 组件本地态等价）
  uint64_t lastFlushSeqNo;      // 最近已落库全局序列号（断线对账锚点，03-8）
};
// 订阅登记（subscription 集合条目；M-05 subscribe 返回句柄）
struct SubEntry {
  Channel ch;                   // S1/W1/T1/E1
  Handle handle;                // M-05 subscribe 返回的订阅句柄
  Throttle throttle;            // 节流/直通规则（03-7）：S1/W1 ≤200ms；T1/E1 直通
  uint64_t lastRefT;            // 最近引用时刻（溢出丢弃 LRU 判定，03-11）
};
// MergeSpan: 合并耗时采样（P-20，ring 环形，RING_CAP=256，仅管理员通道可见）
struct MergeSpan {
  uint64_t enterT;              // 进入 applyDelta 时刻（调用链打点进入）
  uint64_t leaveT;              // 离开 applyDelta 时刻（调用链打点离开）
  uint64_t mergeUs;             // 合并耗时（leaveT - enterT）
};
// tie-breaker（03-3）：timeVirt 相等 → seqNo 大者为准（全局单调，M-07 事件序列号）
// freeze 策略（03-6）：getState 平铺构造（O(通道数) 引用拷贝）+ 顶层 Object.freeze；
//   底层大对象（波形数组等）共享引用不复制不深冻，文档约定视图只读（开销口径见 3.1）

2.3 数据流说明

事件驱动流（4.1.3.4）：事件流到达（M-05 分发）→ 节流窗口合并（applyDelta，≤200ms）→ 通知相关视图重渲染（M-02）；断线恢复流：断线重连 → reconcile 对账补齐（M-07 resumeBySeq）→ 恢复视图一致。

3 实现设计

3.1 getState(viewId) 读取视图状态快照

getState(viewId)：按视图 id 输出**平铺只读 StoreState**（6 字段，与 M-02 v1.4 render(storeState) 消费结构完全一致，03-9/N26）；未订阅通道字段为空态对象（02-5 子集语义）；引用共享 + 顶层 Object.freeze（03-6）；M-02 render 消费；同输入同输出确定性。开销口径：每次调用 O(通道数 ≤4) 引用拷贝 + 顶层冻结，底层大对象共享引用不复制（03-6）。伪代码如下：

// getState: 读取视图状态快照（表24；输出：只读状态对象）
ReadOnlyState getState(string viewId) {
  out = { timeVirt: curTimeVirt, version: curVersion,   // 平铺完整字段（03-9，M-02 v1.4 消费一致）
          sim:    viewChannels(viewId).has(S1) ? channelState.sim    : emptySim,
          wave:   viewChannels(viewId).has(W1) ? channelState.wave   : emptyWave,
          term:   viewChannels(viewId).has(T1) ? channelState.term   : emptyTerm,
          events: viewChannels(viewId).has(E1) ? channelState.events : emptyEvents };
  return freezeTop(out);                          // 顶层冻结；嵌套对象约定只读（03-6）
}
// freeze 策略（03-6）：O(通道数) 引用拷贝 + 顶层 Object.freeze；波形等大数组共享引用不深冻
// 子集语义（02-5）：未订阅通道字段为空态对象；视图私有态（storeMap）不进入交付结构（N26 修复）
// 只读语义：视图写入顶层抛出；嵌套修改破坏一致性 → 文档约定视图只读（4.1.3.1）

3.2 applyDelta(delta) 合并增量状态

applyDelta(delta)：输入协议增量（simStateDelta 等），按虚拟时间戳合并 + tie-breaker（03-3），输出变更通知；节流窗口 leading-edge/trailing-edge（03-1/03-2，与 M-02 02-3 同语义）；T1/E1 直通分支（03-7）；窗口缓冲仅聚合、flush 一次性落库（03-4）；进入/离开打点采样（P-20）。节流/直通规则（throttleFor，03-7）：S1/W1 → 节流 ≤200ms；T1/E1 → 直通实时通知。伪代码如下：

// applyDelta: 合并增量状态（表24；输入：协议增量；按虚拟时间戳合并；输出：变更通知）
ChangeNotice applyDelta(Delta delta) {
  span = {enterT: now, leaveT: 0, mergeUs: 0};   // 调用链打点进入（P-20）
  if (delta.timeVirt < curTimeVirt ||            // 虚拟时间戳旧者丢弃（4.1.3.5）
      (delta.timeVirt == curTimeVirt && delta.seqNo < lastSeqNo))
    { span.mergeUs = now - span.enterT; mergeSpan.append(span); return DROP_STALE; }
  if (delta.ch in {T1, E1}) {                    // 直通分支（03-7）：免节流实时合并+通知
    mergeInto(channelState[delta.ch], delta);    // 直接落通道状态单例（03-5）
    notifyViews(NotifiedDelta{viewIds(delta.ch), delta, lastSeqNo+1});  // 03-10 载荷
    span.mergeUs = now - span.enterT; mergeSpan.append(span); return NOTIFIED;
  }
  if (throttlePending == null) {                 // 开节流窗口（≤200ms，4.1.3.2）
    throttlePending = {}; armTimer(200ms);       // throttleTimer
    notifyViews(NotifiedDelta{viewIds(delta.ch), delta, lastSeqNo}); // leading-edge 立即通知（03-1/03-2）
  }
  mergeInto(throttlePending, delta);             // 窗口缓冲仅聚合（03-4，不落库）
  lastSeqNo = max(lastSeqNo, delta.seqNo);       // 全局单调（03-3/03-8）
  span.mergeUs = now - span.enterT; mergeSpan.append(span);   // 打点离开（P-20）
  return QUEUED;
}
// flush（throttleTimer 到期，trailing-edge 03-2）：
//   一次性落 channelState + storeMap[viewId].lastFlushSeqNo 推进 + notifyViews(NotifiedDelta{...})
//   清空 throttlePending；窗口内无新增量（已 leading 通知）→ 不重复通知

3.3 subscribe(channel) / unsubscribe 订阅与退订

subscribe(channel)/unsubscribe：订阅/退订事件通道，调用 M-05 subscribe，输出订阅句柄；订阅溢出（SUB_CAP=64，估算基线）→ 按优先级丢弃（03-11：LRU 非核心通道；E1 关键事件通道不丢）+ 活跃视图引用自动重订阅；退订释放句柄。伪代码如下：

// subscribe: 订阅事件通道（表24；调用 M-05 subscribe；输出：订阅句柄）
Handle subscribe(Channel ch) {
  if (subscription.size >= SUB_CAP) {            // 订阅溢出（4.1.3.5）
    victim = lruVictim(subscription);            // 03-11：LRU 丢弃非核心通道
    if (victim == null) return REJECTED;         // 全为核心通道（E1）→ 拒绝新订阅 + WARN
    drop(victim); m21Log(WARN, "STORE", "sub_overflow", victim);
    if (viewActiveUses(victim))                  // 活跃视图引用的通道（03-11）
      autoResubscribe(victim, backoff 1s);       // 延迟自动重订阅，避免停更
  }
  h = m05Subscribe(ch);                          // 调用 M-05 subscribe（订阅句柄）
  subscription.add({ch, h, throttleFor(ch), now}); // 节流/直通规则（03-7）+ LRU 引用时刻
  return h;                                      // 输出：订阅句柄
}
// throttleFor（03-7 规则表）：S1 → 节流 ≤200ms；W1 → 节流 ≤200ms；
//   T1 → 直通（串口追加字节实时）；E1 → 直通（关键事件 breakpointHit/trap/paused 实时）
// unsubscribe: 退订（表24）
void unsubscribe(Channel ch) {
  m05Unsubscribe(subscription[ch].handle);       // 释放 M-05 侧句柄

3.4 reconcile() 断线对账

reconcile()：断线对账，按序列号补齐缺失状态；seqNo 全局单调（03-8）；缺口探测由 M-07 重连通知驱动（事件驱动，非轮询）；调用 M-07 resumeBySeq（缺口 → E_PROTO-05，M-07 v1.1 契约）；输出补齐后的状态；恢复视图一致（4.1.3.4）。待恢复态：UI 占位展示（加载中 + 缺口条数），退出条件 = reconcile 成功补齐；重试 ≤3 失败 → 视图级提示 + 定时自动重连重试（≤30s，03-8）。伪代码如下：

// reconcile: 断线对账（表24；调用 M-07 resumeBySeq；输出：补齐后的状态）
StoreState reconcile() {
  gap = probeSeqGap(lastFlushSeqNo);             // 缺口探测：M-07 重连通知驱动（03-8，非轮询）
  if (noSeqGap(gap)) return snapshot();          // 无缺口 → 直接快照
  delta = m07ResumeBySeq(lastFlushSeqNo);        // 全局单调 seqNo（03-8）；缺口 → E_PROTO-05
  applySeqInOrder(delta);                        // 按序列号补齐缺失状态 → channelState 落库
  notifyViews(NotifiedDelta{viewIds(all), delta, lastSeqNo});  // 03-10 载荷
  setViewState(READY);                           // 待恢复态退出（03-8）
  return snapshot();                             // 输出：补齐后的状态
}
// 待恢复态（03-8）：reconcile 期间视图显示占位（"补齐中 · 缺口 N 条"）；
//   退出条件：reconcile 成功 → READY；重试 ≤3 失败 → 视图级提示手动刷新 + 定时自动重连重试 ≤30s

6.1 错误码与处置（源表16 既有码，无新增）

6.2 边界与降级

（1）订阅溢出：LRU 丢非核心通道 + 告警（4.1.3.5）；E1 关键事件通道（breakpointHit/trap/paused）不丢；被丢通道若活跃视图引用 → 自动重订阅（退避 ≤1s）+ 视图级提示（03-11）。
（2）状态版本冲突：以虚拟时间戳新者为准（4.1.3.5）；timeVirt 相等 → seqNo 大者为准，旧增量丢弃（applyDelta 返回 DROP_STALE，03-3）。
（3）节流失效：丢弃合并窗口（未落增量），下次事件重开窗口；channelState/storeMap 保持已落权威状态（两态分离，03-4）。
（4）断线对账：reconcile 经 M-07 resumeBySeq 补齐（全局单调 seqNo，03-8）；E_PROTO-05 持续缺口 → 重试 ≤3 次 → 视图待恢复占位（"补齐中 · 缺口 N 条"）+ M-21 日志 + 定时自动重连重试 ≤30s；补齐后 notifyViews 恢复视图一致（4.1.3.4）。
（5）通道子集为空：ViewComponent.channels 未声明 → 不订阅不合并，getState 返回空态（M-01 01-2 首进入默认态）。
（6）只读防篡改：getState 返回平铺 + 顶层冻结对象，视图写入抛出；嵌套对象约定只读（4.1.3.1、03-6）。
（7）mergeSpan 溢出：ring（256 条，估算基线）丢最旧打点，不影响合并主路径（P-20）。
（8）移动端：375px 可读（NFR-05），状态面板单列 + 横向滚动；file:// 直接可开。
（9）节流级联（03-1）：M-03 合并节流（状态层）与 M-02 渲染节流（DOM 层）解耦——状态层 leading-edge 首增量立即通知（02-3 语义双侧同步），DOM 层仅按合并 flush 触发一次渲染；端到端 UI 刷新上界 = 合并窗口 ≤200ms + DOM 帧 ≤16ms ≈ ≤216ms（估算基线），不再级联叠加为 400ms。
（10）通道共享（03-5）：S1/W1/T1/E1 全局单例（channelState），多视图引用共享；storeMap 仅视图私有态；单通道更新只改一份，一致性天然保证。
