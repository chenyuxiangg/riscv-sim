1 功能概述

1.1 模块定位

M-18 探针（4.5.1）：双源探针（决策点 4）——总线级 trace（底）+ 外设级探针（面）。总线级 trace：监听地址读写事件流（每访存记录时间戳 + 地址 + 方向 + 宽度），覆盖全部访存，语义少噪声大，作事件流底与访存 trace（供 M-11 导出）；外设级探针：外设模型内埋点回调，暴露语义丰富信号（GPIO 翻转、定时器比较、中断脉冲、按键状态），作波形通道（供 M-19）。双源探针均只读观测，不修改仿真状态（2.2 只读约束）。采样可整体关闭（性能开关）。总线 trace 仅自研 ISS 提供（评审 H3），QEMU 后端按 M-17 能力位协商降级、探针接口保持不变。跨模块决议落实：N1（M-15 periph_probe 为探针上报函数、M-14 外设预检走 periph_precheck 独立接口）、N2（M-16 中断脉冲直连本模块探针通道）、N3（定时器比较通道信号源=M-16 mtime/mtimecmp，M-15 Timer 外设 CMP/PRE 透传）、N4（中断位统一命名 MEIE）。

1.3 MVP 范围与预留

MVP 实现范围：attachTrace(bus)（挂接 M-14 总线访存钩子 → traceStream）、attachSignal(periph, ch)（挂接 M-15 外设 probe 回调 → 通道绑定）、sample(time, ch, value)（边沿判定与产出边沿事件）、setRate(cfg)（采样配置：通道使能 + 采样率降载 + 性能开关）；自研 ISS 形态（总线 trace 可用）。
预留项（P1 演进承接，不属现实现）：GPIO 波形/逻辑分析（FR-10）；跨板波形同一时间轴（FR-27，P1，经 M-18/M-19 链路通道）；多通道扩展（channelDefMap 注册表 >4）；QEMU 后端总线 trace（评审 H3 能力位协商，当前降级不可用）。

2 数据描述

2.1 核心数据结构（源文档表68）

数据结构类型定义与用途
channelDefMapMap<ch, {source, signal}>通道定义（默认 ≥4：定时器比较 / GPIO0 / 中断脉冲 / 按键）
sampleCfgstruct采样配置（通道使能、采样率可配降载）
traceStreamstream总线 trace 事件流（时间戳 + 地址 + 方向 + 宽度）

2.1.1 复杂结构字段定义

channelDefMap 决定信号来源与通道绑定（可扩展注册表）；sampleCfg 控制使能与降载（masterEnable 性能开关可整体关闭）；traceStream 为总线级全量访存事件流（底），与波形边沿事件（面）独立。字段定义如下：

// channelDefMap: 通道定义（4.5.1.2 表68；默认 ≥4 通道，注册表可扩展）
struct ChannelDef {
  uint8_t  ch;         // 通道号
  string   source;     // 信号来源（M-15 外设 / M-16 中断控制器）
  string   signal;     // 信号名
  bool     singleBit;  // 单 bit 信号（18-3：kind 升降沿仅适用单 bit 通道）
  uint8_t  valueWidth; // 采样值宽度（18-3：定时器通道 64 位，不截断；GPIO 按端口位宽）
  bool     pulse;      // 脉冲通道（18-2：每次事件均产出，不参与值比较）
};
Map<uint8_t, ChannelDef> channelDefMap;
//   ch=0 定时器比较：source=M-15 Timer 外设 CMP/PRE，signal=timer-compare，
//        valueWidth=64（18-3：不截断）；N3：MVP 定时中断权威源 = M-16 mtime/mtimecmp
//        （CLINT 经 MMIO），Timer 外设 CMP/PRE 透传 mtime 写事件统一映射
//   ch=1 GPIO0：source=M-15 GPIO 外设，signal=gpio0，valueWidth=按端口位宽（FR-10）
//   ch=2 中断脉冲：source=M-16 中断控制器，signal=irq_pulse，pulse=true（18-2）
//        （N2：M-16 irq_request 直连本模块探针上报，每次请求均产事件）
//   ch=3 按键：source=M-15 按键外设，signal=key-state（前端注入事件时间戳化入流）
// sampleCfg: 采样配置（通道使能、采样率可配降载；性能开关可整体关闭）
struct sampleCfg {
  bitmask enable;        // 通道使能位（按 ch 索引 channelDefMap）
  uint32_t sampleRateHz; // 采样率（18-4：sample 内实现节流，每 N 次回调取 1）
  uint8_t  throttleN;    // 节流系数（每 N 次回调取 1；或按虚拟时间间隔过滤）
  bool     masterEnable; // 性能开关：false=整体关闭采样（零开销路径）
};
// TraceEvent: 总线 trace 事件（每访存记录；traceStream 条目，供 M-11 导出）
struct TraceEvent {
  uint64_t t;     // 时间戳（虚拟时间，M-12 权威源）
  uint32_t addr;  // 访问地址
  uint8_t  width; // 访问宽度（8/16/32，对齐 M-14 on_bus_access 签名，18-8）
  uint8_t  dir;   // DIR_READ / DIR_WRITE
};
// traceStream: 总线 trace 事件流（底），独立于波形边沿事件（面），不并入 M-19
//   18-1：环形窗口（cap 默认 2×10⁵ 条，估算基线实现后实测校准），溢出丢最旧 + dropped 计数；
//   18-5：M-18 为事件源，M-11 recordTrace 订阅消费（单链，不做双缓冲复制）
struct traceStream {
  TraceEvent buf[TRACE_CAP];  // 定长环形窗口（默认 TRACE_CAP=2×10⁵）
  uint32_t   head;            // 写游标
  uint64_t   dropped;         // 溢出丢弃计数（丢最旧 + 标记）
  uint64_t   seq;             // 事件序（单调，供 M-11 订阅续拉/导出聚合）
};
// EdgeEvent: 边沿事件（送 M-19 边沿编码）
struct EdgeEvent {
  uint64_t t;     // 时间戳（虚拟时间）
  uint8_t  ch;    // 通道号（channelDefMap 键）
  uint64_t value; // 当前值（宽度按通道 valueWidth，18-3：定时器 64 位不截断）
  uint8_t  kind;  // 0=rising / 1=falling（18-3：仅单 bit 通道判升降；多 bit 只产 value 变化）
};

2.2 缓存与增量语义

机制语义实现通道备注
边沿判定只记变化点：sample 同值重复不产出，值变化才产出边沿事件EdgeEvent + prev[ch]波形数据量受控（2.5：边沿只记变化点）
trace 独立traceStream 全量访存事件（底）独立成流供 M-11 导出；环形窗口（18-1）+ M-11 订阅消费（18-5）traceStream + m11Subscribe双源解耦（4.5.1.4）；不做双缓冲复制
采样降载通道使能 + 采样率可配（throttleN 节流在 sample 内生效，18-4）；性能开销超限自动降采样sampleCfg.sampleRateHz + throttleN波形刷新 ≤200ms 估算基线
性能开关masterEnable=false 整体关闭采样（零开销路径）sampleCfg.masterEnable性能开关（4.5.1.1）
时间基准事件时间戳=虚拟时间（M-12 权威源），跨模块同一基准t = timeVirt确定性约束（2.4 表6）

2.3 数据流说明

总线访存 / 外设 probe → 边沿判定（只记变化点）→ 产出边沿事件 → 送 M-19；trace 独立成流供 M-11 导出（4.5.1.4）。

3 实现设计

3.1 attachTrace(bus) 挂接总线访存事件

attachTrace(bus)：总线级 trace（底）——挂接 M-14 总线访存钩子（on_bus_access(ts, addr, width, dir)，签名对齐 M-14 v1.3，18-8），每访存写入 traceStream 环形窗口（18-1：容量 2×10⁵，溢出丢最旧 + dropped 计数）；M-11 recordTrace 订阅消费（18-5：单链，不做双缓冲复制）；仅自研 ISS 提供（评审 H3，QEMU 按 M-17 能力位降级）。伪代码如下：

// attachTrace: 挂接总线访存事件（4.5.1.3 表69；输入：M-14 访存钩子）
void attachTrace(Bus bus) {
  if (!cap(TRACE_SUPPORTED)) return;              // QEMU 无总线 trace（评审 H3，能力位协商降级）
  bus.on_bus_access((ts, addr, width, dir) => {   // 18-8：签名对齐 M-14 v1.3
    TraceEvent ev = {t: ts, addr, width, dir};     // 每访存记录（时间戳+地址+宽度+方向）
    if (traceStream.full()) {                      // 18-1：环形窗口溢出
      traceStream.dropped++;                       // 丢最旧 + 计数标记（不阻塞仿真）
      traceStream.head = (head + 1) % TRACE_CAP;
    }
    traceStream.append(ev);                        // 输出：traceStream 写入（事件源）
    m11Subscribe(ev);                              // 18-5：M-11 recordTrace 订阅消费（单链）
  });
}

3.2 attachSignal(periph, ch) 挂接外设信号探针

attachSignal(periph, ch)：外设级探针（面）——挂接 M-15 外设模型内 probe 回调（periph_probe(p, sig, v, t)，探针上报函数），绑定到 channelDefMap 通道；绑定在挂接时一次性完成（18-6），同 ch 冲突拒绝 + WARN（E_CTX-02 语义）；采样由 sample() 统一判定产出。跨模块决议 N1：M-15 的 periph_probe 仅为探针上报（void），外设可访问性预检由 M-14 走独立接口 periph_precheck(p, off)，两接口语义分离、命名不冲突。伪代码如下：

// attachSignal: 挂接外设信号探针（4.5.1.3 表69；输入：Peripheral.probe 回调）
void attachSignal(Peripheral periph, uint8_t ch) {
  // 18-6：绑定在挂接时一次性完成（不进回调）；同 ch 冲突 → 拒绝 + WARN（E_CTX-02 语义）
  if (channelDefMap.has(ch)) { log(WARN, "probe", "conflict", "E_CTX-02"); return; }
  channelDefMap[ch] = {source: periph.id, signal: sig, singleBit, valueWidth, pulse};
  // N1：M-15 periph_probe(p, sig, v, t) = 探针上报（void，经本接口进入采样判定）；
  //     外设预检为独立接口 periph_precheck(p, off)（M-14 调用），与本接口互不冲突
  periph.onProbe((sig, v, t) => {                  // M-15 模型内埋点回调
    sample(t, ch, v);                              // 统一进采样判定（边沿/脉冲/节流）
  });
}

3.3 sample(time, ch, value) 边沿判定与产出

sample(time, ch, value)：采样判定——脉冲通道（18-2：中断脉冲）每次事件均产出、不参与值比较；单 bit 通道判升降沿（kind，18-3）；多 bit 通道只产 value 变化事件（不判升降）；采样率节流（18-4：每 N 次回调取 1）；masterEnable=false 零开销直接返回。伪代码如下：

// sample: 采样判定与产出（4.5.1.3 表69；输出：边沿事件）
EdgeEvent sample(uint64_t time, uint8_t ch, uint64_t value) {
  if (!sampleCfg.masterEnable) return null;        // 性能开关：整体关闭（零开销路径）
  if (!sampleCfg.enable[ch]) return null;          // 通道未使能
  if (--throttleCounter[ch] > 0) return null;      // 18-4：采样率节流（每 throttleN 次取 1）
  throttleCounter[ch] = sampleCfg.throttleN;
  ChannelDef def = channelDefMap[ch];
  if (def.pulse) {                                 // 18-2：脉冲通道事件直通
    EdgeEvent ev = {t: time, ch, value, RISING};   // 每次事件均产出（不参与值比较）
    prev[ch] = value; m19Encode(ev); return ev;    // 同线号重复请求不丢失
  }
  if (value == prev[ch]) return null;              // 只记变化点：同值重复不产出
  uint8_t kind = def.singleBit ? (value ? RISING : FALLING) : KIND_NA;
                                                   // 18-3：kind 仅单 bit 通道；多 bit 不判升降
  prev[ch] = value;                                // 更新旧值基准
  EdgeEvent ev = {t: time, ch, value, kind};       // 输出：边沿事件（送 M-19 编码）
  m19Encode(ev);                                   // 下游：M-19 边沿编码入环
  return ev;
}

3.4 setRate(cfg) 采样配置与降载

setRate(cfg)：采样配置——通道使能、采样率可配降载（写入 sampleCfg.throttleN，sample 内生效，18-4）；性能开销超限（overheadBudgetExceeded 度量口径：事件产出率 > 预算事件率阈值 或 探针路径 CPU 占比 > 5%，18-4）→ 自动降采样并提示（保持波形刷新 ≤200ms 估算基线）。伪代码如下：

// setRate: 采样配置（4.5.1.3 表69；输出：确认）
uint8_t setRate(sampleCfg cfg) {
  sampleCfg = cfg;                                 // 通道使能 + 采样率 + 性能开关
  sampleCfg.throttleN = ceil(sampleRateHz / targetRateHz); // 18-4：节流系数生效
  if (overheadBudgetExceeded()) {                  // 探针性能开销超限（4.5.1.5）
    sampleCfg.throttleN *= 2;                      // 自动降采样（节流加倍，sample 内生效）
    log(WARN, "probe", "downgrade", "overhead");   // 提示（保持波形刷新 ≤200ms 基线）
  }
  return OK;                                       // 输出：确认
}
// overheadBudgetExceeded（18-4 度量口径）：事件产出率 > 预算事件率阈值（如 10⁶ 事件/s）
//   或探针路径 CPU 占比 > 5%（采样自耗时计数器），任一成立即视为超限

3.5 中断脉冲 / 定时器探针接线（跨模块决议 N2/N3）

通道 ch=2（中断脉冲）与 ch=0（定时器比较）的信号源接线明确如下：

// N2（中断脉冲）：M-16 irq_request 直连本模块探针通道，不再 periph_probe(NULL, "irq_pulse", ...)
void m16IrqPulse(uint64_t t, uint32_t irqLine) {
  if (sampleCfg.enable[CH_IRQ_PULSE])
    sample(t, CH_IRQ_PULSE, irqLine);              // 18-2：脉冲通道事件直通（每次请求均产出）
}                                                  //   同线号重复请求不丢失（不参与值比较）
// N3（定时器比较）：MVP 定时中断权威源 = M-16 mtime/mtimecmp（CLINT 语义经 M-14 MMIO）
//   M-15 Timer 外设 CMP/PRE 透传 mtime 写事件 → 本通道统一映射，两套定时器不各自产线
void m15TimerCompare(uint64_t t, uint64_t cmp) {
  if (sampleCfg.enable[CH_TIMER_CMP])
    sample(t, CH_TIMER_CMP, cmp);                  // 18-3：value 64 位不截断（valueWidth=64）
}

6 异常处理

6.1 错误码与处置（无新增码）

M-18 为只读观测模块（2.2：探针/波形/trace 只读，不修改仿真状态），不新增错误码；异常统一按以下处置：

错误码 / 场景触发条件处置
通道溢出探针边沿事件产出速率超 M-19 环形缓冲容量按 M-19 overflowPolicy（丢最旧 + 标记 / 暂停仿真，可配）
性能开销超限探针采样开销超预算（波形刷新 >200ms 估算基线）自动降采样（sampleRateHz 减半）并提示
能力不足QEMU 后端无总线 trace（评审 H3）attachTrace 不挂接；按 M-17 能力位协商降级，接口不变
无效通道 / 绑定冲突attachSignal / sample 引用未注册通道；同 ch 重复绑定（18-6）拒绝挂接/采样 + 日志（WARN，E_CTX-02 语义），不产出事件

6.2 边界与降级

（1）QEMU 后端：总线 trace 不可用（评审 H3）→ attachTrace 不挂接，波形（外设面）仍可用；前端按 M-17 能力位提示。
（2）性能开关：masterEnable=false → 采样整体关闭（零开销路径，4.5.1.1）。
（3）自动降采样：性能开销超限 → throttleN 加倍 + 提示（18-4）；仍超限 → 进一步降采样直至满足 ≤200ms 基线。
（4）traceStream 溢出（18-1）：环形窗口满 → 丢最旧 + dropped 计数标记（不阻塞仿真），不并入 M-19 溢出策略。
（5）通道溢出（边沿/脉冲）：按 M-19 溢出策略（丢最旧 + 标记，默认；暂停仿真可配）。
（6）同 ch 绑定冲突（18-6）：拒绝 + WARN（E_CTX-02 语义）。
（7）跨模块接线：N1（periph_probe=上报 / periph_precheck=预检分离）、N2（M-16 中断脉冲直连本模块，脉冲事件直通 18-2）、N3（定时器比较通道统一映射 M-16 mtime/mtimecmp，M-15 Timer CMP/PRE 透传，value 64 位 18-3）、N4（MEIE 命名统一）；M-14 钩子签名 on_bus_access(ts, addr, width, dir)（18-8）。

7.2 可维护性手段

（1）通道注册表可扩展：channelDefMap 注册制新增通道不改判定逻辑。
（2）双源解耦：trace 底（全量访存）与信号面（边沿事件）独立流，互不耦合。
（3）采样配置结构化：通道使能/采样率/性能开关为显式配置，调整不涉核心逻辑。
（4）能力位协商：总线 trace 与能力面解耦（评审 H3），QEMU 降级不改接口。
（5）CI 门禁：边沿只记变化点 + 数据量受控用例纳入回归基线。
