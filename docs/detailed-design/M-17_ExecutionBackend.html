1 功能概述

1.1 模块定位

M-17 ExecutionBackend 执行后端抽象：隔离「如何执行指令」与「如何调试/观测」，调试服务（M-08~M-11）只面对抽象接口，不感知具体内核实现（4.4.6.1）。双内核适配：自研 ISS（M-13，WASM，全量能力 L3）与 QEMU（服务端可选，进程隔离 + 标准 RSP/QMP 交互，声明 L1 子集，合规 R2/R5 工程红线）。能力协商由 M-04/M-05 完成，不足时前端降级；「总线 trace 底」仅自研 ISS 提供（评审 H3）。

能力分级语义：L1 = 基础调试（执行控制/断点/寄存器内存/镜像与符号）；L2 = L1 + 指令/访存钩子（onInstruction/onAccess）；L3 = L2 + snapshot/restore 与事件流检查点（FR-19）。自研 ISS 全量 L3；QEMU 声明 L1 子集（3.2.4 表13）。

1.3 MVP 范围与预留

MVP 实现范围：抽象接口与代理分发（vtable 代理）、自研 ISS（M-13）全量 L3 适配、能力协商（negotiateCap 与 capBitsSet 公布）、执行控制/断点/寄存器内存/镜像符号代理、L2 指令/访存钩子（onInstruction/onAccess，供断点/trace/探针/覆盖率复用）、L3 快照（snapshot/restore → M-20）、后端异常日志（M-21）。

预留项（P1/P2 演进承接，不展开实现）：QEMU 后端适配（P1，FR-15 GDB RSP 兼容；进程隔离 + RSP/QMP 映射 L1 子集）；多核/SMP（P2，FR-18，扩展预留）；反向调试/快照回放深化（P1，FR-19，配合 M-20/M-23）；watch 符号表达式（P1，E_CTX-08）。

2.1.1 复杂结构字段定义

BackendHandle 是执行后端的实例句柄；CapLevel 定义能力位语义；HookTable 为 L2 钩子注册表。字段定义如下：

// BackendHandle: 后端实例句柄（代理分发核心）
struct BackendHandle {
  BackendType type;          // self_iss / qemu（枚举）
  CapLevel    capLevel;      // 已协商能力级：L1/L2/L3（self_iss=L3；qemu=L1 子集）
  BackendVtbl vtable;        // 实现表（成员全量清单见下；按能力位裁剪，未实现成员 = NULL）
  uint8_t     capBits;       // 能力位集合（capBitsSet 低 3 位：L1/L2/L3 位），向前端公布
  uint32_t    state;         // 运行状态：0=ready / 1=running / 2=paused / 3=faulted
  PauseInfo   lastPause;     // 最近一次暂停信息（原因/PC/虚拟时间，见下）
  void*       implState;     // 实现私有状态：self_iss → ISS 实例；qemu → 子进程/RSP 会话句柄
};
// BackendVtbl: 实现表成员全量清单（17-5；step 与 runUntil 语义分离，见 3.1）
struct BackendVtbl {
  PauseInfo (*runUntil)(BackendHandle*, uint64_t t);  // 时间驱动（self_iss 精确；qemu 尽力而为，17-2）
  PauseInfo (*step)(BackendHandle*);                  // 指令驱动：执行 1 条后暂停（17-1）
  err_t (*readReg)(BackendHandle*, const char* name, uint32_t* out);
  err_t (*writeReg)(BackendHandle*, const char* name, uint32_t val);
  err_t (*readMem)(BackendHandle*, uint32_t addr, uint8_t width, uint32_t* out);
  err_t (*writeMem)(BackendHandle*, uint32_t addr, uint8_t width, uint32_t val);
  err_t (*loadELF)(BackendHandle*, const uint8_t* binary, size_t len);
  err_t (*installSymbols)(BackendHandle*, const uint8_t* dwarf, size_t len);
  err_t (*bp)(BackendHandle*, uint32_t addr, BpId* id);        // 无条件断点（qemu：RSP Z0）
  err_t (*bpHook)(BackendHandle*, uint32_t addr, CondFn cond, BpId* id); // 条件断点（self_iss：L2 钩子）
  err_t (*bpControl)(BackendHandle*, BpId id, uint8_t op);     // 断点生命周期（08-2 联动，v1.2）：
                                                                //   op：0=REMOVE（注销）/ 1=ENABLE（启用）/ 2=DISABLE（停用）
                                                                //   self_iss：hookTable 移除 / 钩子启用位；qemu：RSP z0 撤销 / Z0 重插
  err_t (*snapshot)(BackendHandle*, Snapshot* s);      // L3；qemu = NULL（降级）
  err_t (*restore)(BackendHandle*, const Snapshot* s); // L3；qemu = NULL（降级）
  // 完整引擎级快照（v1.3，2026-10-20 收口轮新增；契约 port.rs::ExecutionBackend）
  //   snapshot_full / restore_full：携带**待处理事件队列**与插入序计数器，
  //   因此可确定性还原**引擎**（M-12 段）。与上面 partial 的 snapshot/restore
  //   的差别：partial 的 SimState 装不下队列，还原后快照之后入队的事件仍会触发。
  //   载体 = 契约层 riscv_sim_contract::snapshot::EngineSnapshotDto（可序列化）。
  //   作用域：只覆盖 M-12/M-17 段；外设（M-15）与中断控制器（M-16）状态
  //   **不在**其中（见 M-20 §2.1.1 的完整 Snapshot 结构）。
  //   降级：不支持的后端返回 E_SNAP-03（**大声失败**，不静默跳过）。
  err_t (*snapshot_full)(BackendHandle*, EngineSnapshotDto* d);      // L3；qemu = NULL（降级）
  err_t (*restore_full)(BackendHandle*, const EngineSnapshotDto* d); // L3；qemu = NULL（降级）
};
// CapLevel: 能力分级（3.2.4 表13 语义）
enum CapLevel {
  L1 = 1,   // 基础调试：执行控制/断点/寄存器内存/镜像与符号
  L2 = 2,   // L1 + 指令/访存钩子（onInstruction / onAccess）
  L3 = 3,   // L2 + snapshot/restore 与事件流检查点（FR-19）
};
// PauseInfo: 暂停信息（执行控制输出；同步语义：runUntil/step 返回即已暂停，
//             reason 枚举无 RUNNING 值，17-4）
struct PauseInfo {
  uint8_t  reason;     // 暂停原因：0=runUntil 到点 / 1=step 完成 / 2=断点命中 / 3=异常 / 4=崩溃
  uint32_t pc;         // 暂停时 PC
  uint64_t time_virt;  // 暂停时虚拟时间（权威源 = M-12 虚拟时钟）
};
// HookTable / HookEvent: L2 钩子（仅自研 ISS 提供；QEMU 不支持 → 协商降级）
struct Hook {                    // 钩子注册项（hookTable 元素，17-6）
  uint8_t  pre;        // 阶段：1=执行前（可拦截暂停）/ 0=执行后（不拦截）
  uint8_t  kind;       // 0=onInstruction（指令）/ 1=onAccess（访存）
  int   (*fn)(HookEvent* ev, void* ctx);  // 返回：pre 阶段 1=拦截暂停（断点命中）；0=继续
  void*    ctx;        // 注册时携带的上下文（断点 id/trace 通道/探针通道）
};
struct HookEvent {
  uint32_t pc;         // 指令地址（onAccess 时 = 访问指令 PC）
  uint32_t addr;       // 访存地址（onAccess；onInstruction 时 = 0）
  uint8_t  width;      // 访存宽度（onAccess；onInstruction 时 = 0）
  uint8_t  dir;        // 访存方向（0=读 / 1=写）
  uint8_t  pre;        // 触发阶段（同 Hook.pre，供回调自识别）
};

2.2 能力分级与双内核矩阵

能力L1 基础调试L2 +指令钩子L3 +快照/检查点自研 ISS（M-13）QEMU（P1）
执行控制 reset/runUntil/step/stepSource√√√全量（时间精确）√（runUntil 尽力而为，17-2）

能力协商语义：会话创建时由 M-04/M-05 完成协商（后端类型 + capLevel），结果公布到 capBitsSet；前端（M-01~M-03）与调试服务按能力位降级——QEMU 下 trace/快照不可用，调用方降级并提示，横切组件接口保持不变（4.7 表86 能力降级规则）。

2.3 数据流说明

下行：M-08~M-11 调试服务经抽象接口代理 → ExecutionBackend 分发到具体实现（self_iss 直接访问 / qemu RSP 命令）；上行：执行控制输出 PauseInfo（原因/PC/虚拟时间）；观测：L2 钩子（onInstruction/onAccess）→ M-18 探针/trace（仅自研 ISS）；记录：后端异常日志 → M-21；快照：snapshot/restore → M-20 事件流与检查点（L3）。

3 实现设计

3.1 抽象接口与代理分发

调试服务只面对抽象接口（3.2.4 表13）：所有调试调用经 BackendHandle.vtable 分发到具体实现；调用方不感知 self_iss 与 qemu 的实现差异。执行控制输出统一为 PauseInfo（原因/PC/虚拟时间）。两条执行路径语义分离（17-1）：runUntil = 时间驱动（推进至虚拟时间 t，同步返回即暂停）；step = 指令驱动（执行 1 条后暂停）。伪代码如下：

// exec_runUntil: 执行控制代理（时间驱动；M-08~M-11 → 抽象接口）
PauseInfo exec_runUntil(BackendHandle* b, uint64_t t, err_t* err) {
    if (b->state != READY && b->state != PAUSED) { *err = E_CTX-02; return (PauseInfo){0}; }  // 暂停态外调用拒绝
    PauseInfo p = b->vtable.runUntil(b, t);   // 同步调用：返回即已暂停（self_iss：M-12 事件驱动推进至 t；
                                              //  qemu：尽力而为，时间不保证精确，17-2）
    b->lastPause = p; b->state = PAUSED;      // reason 枚举见 2.1.1（无 RUNNING，同步语义，17-4）
    *err = OK; return p;
}
// exec_step: 指令级单步 —— 直接代理 vtable.step（指令驱动，与 runUntil 分离，17-1）
PauseInfo exec_step(BackendHandle* b, err_t* err) {
    if (b->state != READY && b->state != PAUSED) { *err = E_CTX-02; return (PauseInfo){0}; }
    PauseInfo p = b->vtable.step(b);          // self_iss：iss_step 执行 1 条后暂停；qemu：RSP 's'
    b->lastPause = p; b->state = PAUSED; *err = OK; return p;
}
// exec_stepSource: 源码级单步 —— 按行映射推进（无映射降级为 step + 提示，M-09；QEMU 同理，17-2）
PauseInfo exec_stepSource(BackendHandle* b, const LineMap* map, err_t* err) {
    ... // self_iss：沿行边界多次 step；qemu：step 近似（行映射缺失降级）
}
// exec_readReg: 寄存器读取代理（含 CSR/PC）
err_t exec_readReg(BackendHandle* b, const char* name, uint32_t* out) {
    if (!(b->capBits & CAP_REG)) return E_CTX-03;  // 能力不足拒绝（QEMU 下寄存器可用，L1）
    return b->vtable.readReg(b, name, out);        // self_iss：直接读 regFile/CSR；qemu：RSP 'p' 命令
}
// exec_setBreakpoint: 断点代理（17-5/17-9）
err_t exec_setBreakpoint(BackendHandle* b, uint32_t addr, CondFn cond, BpId* id) {
    if (b->capLevel < L2 || cond == NULL) return b->vtable.bp(b, addr, id);      // qemu：RSP Z0（无条件）
    return b->vtable.bpHook(b, addr, cond, id);      // self_iss：L2 条件断点（指令钩子实现）
    // QEMU 下传 cond：降级为无条件断点 + WARN 日志（17-9），由 qemu_bp 内部处理
}
// exec_bpControl: 断点生命周期代理（08-2 联动，v1.2：M-08 remove/enable/disable 统一入口）
err_t exec_bpControl(BackendHandle* b, BpId id, uint8_t op) {   // op：0=REMOVE / 1=ENABLE / 2=DISABLE
    if (b->vtable.bpControl == NULL) return E_CTX-03;           // 能力不足拒绝（L1 基础能力，不应发生）
    return b->vtable.bpControl(b, id, op);                      // self_iss：hookTable 操作；qemu：RSP z0/Z0
}

3.2 自研 ISS 适配（M-13，全量 L3）

MVP 主实现：自研 ISS（WASM）直接承接执行后端——执行控制代理到 M-12/M-13（事件驱动推进、量子边界采样），寄存器/内存直接访问（M-13 regFile/CSR、M-14 总线），断点用 L2 指令钩子实现（M-08 PC 命中优先于全量回调，性能基线 0.5–1 MIPS 调试态）。钩子调用点（17-6）：onInstruction 在 M-13 译码后（pre=1，执行前）与指令执行完成后（pre=0，执行后）两处调用——pre 钩子可返回拦截（断点命中语义，指令不执行）；post 钩子不拦截，供 trace/覆盖率；onAccess 在 M-14 访存路径调用（读/写事件，不拦截）。钩子按需注册（hookTable），未注册路径零开销。快照（L3）：snapshot/restore 序列化 regFile/CSR/pc/privMode（M-13）+ 内存/映射（M-14）+ 外设状态（M-15），经 M-20 契约上链。伪代码如下：

// self_iss 实现表（vtable 绑定到 M-13/M-12/M-14 具体接口）
static BackendVtbl iss_vtable = {
    .runUntil  = iss_runUntil,    // → M-12 事件驱动推进至虚拟时间 t（量子配额 + 事件分发）
    .step      = iss_step,        // → M-13 执行 1 条指令后暂停（指令驱动，17-1）
    .readReg   = iss_readReg,     // → M-13 regFile/CSR 直读（含 PC）
    .writeReg  = iss_writeReg,    // → M-13 直写（暂停态）
    .readMem   = iss_readMem,     // → M-14 bus_read（未映射 → E_BUS-01 上报）
    .writeMem  = iss_writeMem,    // → M-14 bus_write
    .loadELF   = iss_loadELF,     // → M-13 段加载（对齐 M-06 解析结果）
    .bp        = iss_bp,          // 无条件断点（内部登记 hookTable，pre=1 拦截）
    .bpHook    = iss_bpHook,      // 条件断点（cond 判定在钩子回调内完成）
    .bpControl = iss_bpControl,   // 断点生命周期：hookTable 移除 / 钩子启用位（08-2 联动，v1.2）
    .snapshot  = iss_snapshot,    // → 序列化 regFile/CSR/pc/privMode → M-20 契约
    .restore   = iss_restore,     // → 恢复 + 清缓存（decodedCache 按 pc 失效）
};
// L2 钩子调用点（M-13 执行流程，17-6）：
//   pre（pre=1）：译码后、指令执行前调用；fn 返回 1 = 拦截暂停（断点命中语义，指令不执行）
//   post（pre=0）：指令执行完成后调用；不拦截（trace/覆盖率）
//   onAccess：M-14 访存路径调用（读/写事件，不拦截）
void iss_onInstruction(uint32_t pc, uint8_t pre, HookEvent* ev) {
    if (!hookTable.has(pc)) return;              // 未注册地址零开销（PC 命中优先，评审 H3）
    for (hook : hookTable[pc]) {
        if (hook.pre != pre) continue;           // 按阶段过滤（pre=0/1 分列，17-6）
        int stop = hook.fn(&ev, hook.ctx);
        if (pre && stop) { pause(bp_hit, pc); return; }  // pre 拦截：暂停，指令不执行
    }
}
// 钩子注册（onInstruction/onAccess）：hookTable[pc] / hookTable[addr] 追加；
// 断点地址禁止缓存解码（自修改代码场景，对齐 M-13 缓存失效策略）
// iss_bpControl: 断点生命周期（08-2 联动，v1.2；op：0=REMOVE / 1=ENABLE / 2=DISABLE）
err_t iss_bpControl(BackendHandle* b, BpId id, uint8_t op) {
    BreakpointRec* r = bpRecTable[id];                 // 断点注册记录（addr/cond/钩子句柄）
    if (r == NULL) return E_CTX-07;                    // 无效断点 id
    if (op == REMOVE) {
        hookTable_remove(r->addr, r->hookHandle);      // 移除钩子（断点地址解除拦截）
        bpRecTable.erase(id);                          // 注销记录
    } else {
        hookTable[r->addr].enabled = (op == ENABLE);   // 钩子启用位（停用不命中、保留注册）
    }
    return OK;
}

3.3 QEMU 适配（P1，L1 子集）

QEMU 后端为服务端可选实现（进程隔离，合规 R2/R5）：子进程 + 标准 GDB RSP 承载调试命令、QMP 承载控制/监控；只映射 L1 子集（执行控制/断点/寄存器内存/镜像符号），L2/L3 能力不声明 → 协商降级（E_CTX-03）。QEMU 交互仅标准协议、不改源码。三条契约差异（17-2/17-3/17-9）：runUntil(t) 为尽力而为（RSP vCont 无虚拟时间语义，运行至事件/断点或步进近似，时间不保证精确）；崩溃恢复 = 重启会话 + 输入事件重放至崩溃前虚拟时间（重执行式，QEMU 无状态快照可序列化）；条件断点 cond 降级为无条件 + WARN 提示。命令映射与会话生命周期如下：

// qemu 实现表（P1）：RSP/QMP 命令映射（仅标准协议，不改 QEMU 源码）
static BackendVtbl qemu_vtable = {
    .runUntil = qemu_runUntil,   // 尽力而为（17-2）：RSP 'vCont' 续跑 + QMP 暂停；
                                 //   语义 = 运行至事件/断点或步进近似，t 不保证精确
    .step     = qemu_step,       // RSP 's' 单步（指令驱动，精确）
    .readReg  = qemu_readReg,    // RSP 'p<regno>' 读寄存器（QEMU 寄存器编号表）
    .writeReg = qemu_writeReg,   // RSP 'P<regno>=<val>' 写寄存器
    .readMem  = qemu_readMem,    // RSP 'm<addr>,<len>' 读内存
    .writeMem = qemu_writeMem,   // RSP 'M<addr>,<len>:<hex>' 写内存
    .loadELF  = qemu_loadELF,    // RSP 'vFile' 镜像加载
    .bp       = qemu_bp,         // RSP 'Z0' 软件断点 / 'z0' 撤销
                                 // cond 非空 → 降级为无条件断点 + WARN 日志（17-9）
    .bpControl = qemu_bpControl, // 断点生命周期（08-2 联动，v1.2）：REMOVE → RSP 'z0' 撤销；
                                 //   ENABLE → 按记录的 addr 重发 'Z0' 重插；DISABLE → 'z0' 撤销
    .snapshot = NULL,            // 不声明 → 降级（L3 不可用）
};
// 能力声明（QEMU）：capBits = L1 位集；onInstruction/onAccess/snapshot 位清零
// 降级路径：调试服务调用 L2/L3 接口 → E_CTX-03 拒绝 + capBitsSet 公布 → 前端隐藏/降级提示
// 崩溃恢复（17-3）：QEMU 无 L3 快照 → 恢复 = 重启子进程 + 输入事件重放至崩溃前
//   虚拟时间（重执行式，无状态快照基）；自研 ISS 才走 M-20 检查点 + 重放（4.4.6.5）
// 会话生命周期（17-8）：
//   启动：spawn + RSP 握手（qSupported），超时 3s → E_CTX-03（实例化失败）
//   无响应：命令超时 500ms → 判定失联 → 重启子进程 + 重载镜像（≤1 次重连）
//   协议错误：RSP 校验失败 → 丢弃重发（幂等命令）或终止会话上报
//   崩溃：退出码非零 / pipe 断开 → HMS report + 重启会话 + 重放

3.4 能力协商与降级

会话创建 → 能力协商（后端类型 + capLevel，M-04/M-05 完成）→ 实例化实现 → 调试服务经抽象代理；能力不足处前端按能力位降级（如 QEMU 下 trace/快照不可用，4.4.6.4）。降级语义：能力位在 capBitsSet 公布，调用方（M-08~M-11、M-18、M-20）按位判断；越权调用 → E_CTX-03 拒绝 + 协商降级提示；横切组件接口保持不变（4.7 表86 能力降级规则）。

6.2 边界与降级

（1）能力降级边界：QEMU 后端声明 L1 子集——指令钩子（onInstruction/onAccess）与快照（snapshot/restore）不可用，调用方（M-08~M-11、M-18、M-20）按 capBitsSet 降级；总线 trace 底仅自研 ISS 提供（评审 H3）。

（2）合规红线：QEMU 交互仅标准 RSP/QMP，不改 QEMU 源码；进程隔离避 GPL 传染（评审 M5，4.4.6.5）。

（3）确定性边界：执行控制输出（PauseInfo 虚拟时间）以 M-12 虚拟时钟为权威，不依赖宿主时钟（2.4 表6）；QEMU 下 runUntil 为尽力而为，虚拟时间不保证精确（17-2），前端按能力位提示。

（4）崩溃恢复边界：QEMU 子进程崩溃 = 平台故障（非 guest trap）；恢复 = 重启会话 + 输入事件重放至崩溃前虚拟时间（重执行式，QEMU 无状态快照可序列化，17-3）；自研 ISS 才走 M-20 检查点 + 重放；恢复前调试服务暂停并上报 HMS（4.4.6.5、8 章表93 韧性）。

（5）性能边界：调试态全钩子 ≥0.5–1 MIPS（估算基线）；钩子按需注册，未注册地址零开销；M-08 PC 命中优先于全量回调（8 章表93）。

确定性夹具同种子 + 同输入序列（含断点/快照操作）跑两遍执行轨迹（PC 序列/暂停点/虚拟时间）完全一致（2.4 表6）
QEMU 崩溃恢复（P1 模拟）模拟子进程异常退出HMS report 上报；重启会话 + 输入事件重放至崩溃前虚拟时间，状态一致（17-3）

7.2 可维护性手段

（1）抽象隔离（8 章表93 可维护性）：调试服务只面对抽象接口，自研 ISS / QEMU 实现细节隔离在 vtable 之下，替换内核不改消费方。

（2）能力位协商内建：capBitsSet 单一事实源，前端/调试服务按位降级；新增能力位向后兼容（NFR-06 插件化）。

（3）钩子按需注册：hookTable 按地址/事件注册，未注册路径零开销；断点命中优先于全量回调（M-08，性能基线）。

（4）日志统一走 M-21：后端异常/崩溃 log 结构化入缓冲，不依赖临时打印。

（5）契约层可替换性（源 2.5 对齐）：本模块对外的 driving 端口收敛到 9.1.1 端口契约表，替代实现（替代执行后端）遵守同端口契约并通过契约测试即可接入，不改动既有会话与调试服务。

9.1.1 端口契约（driving/driven，源文档表67→80 对齐）

端口 / 服务方向契约（输入 → 输出；错误码/约束）
