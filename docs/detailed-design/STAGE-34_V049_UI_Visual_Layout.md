## §1 目标与边界

### §1.1 本批要达成的

1. **导航形态**：顶部标签页 ⇒ ⇒ **左侧分组侧边栏**（「运行与调试」5 项 / 「平台」3 项）。
2. **设计语言**：换成原型的深色卡片式（青色主色 / 等宽数值 / 圆角卡片 / 提示条 / 空态）。
3. **顶栏全局运行条**：品牌 + 连接状态胶囊 + **PC / 虚拟时间 / 运行 / 单步 / 复位 / 加载固件**。

### §1.2 事实表（实测 · F1~F12）

| 号 | 事实 |
| --- | --- |
| F1 | 当前顶栏是 `<header class="topbar">`：brand + `data-image-load-slot` + `<nav id="workbench-tabs">`（**7 个** `<a class="tab">`）+ `seed-demo` 按钮 + `#status` 文本（`front/index.html`） |
| F2 | 导航项的**稳定标识**是 `data-view-tab` 属性，**当前项**由 `aria-current="page"` 标记（`front/views/m01_workbench.js` 的 `syncTabState`） |
| F3 | 路由是 **hash 路由**：`location.hash` ⇒ `route()` ⇒ `VIEW_REGISTRY` ⇒ `switchView()` ⇒ `mountPanels()` / `showPanel()`（M-01 §3.2） |
| F4 | 视图面板由 `createPanel()` **动态创建**：`<section data-view-panel="...">` + `<h2>`（用 `v.name`）+ `div.view-body` |
| F5 | **真机门禁 92 条断言没有一条用 tab 选择器** ⇒ ⇒ 它们走 `location.hash` 与 `[data-view-panel]` ⇒ ⇒ **改导航形态不会让判据口径悄悄变**（这正是 STAGE-33 踩过的坑） |
| F6 | 前端**用例**有 **3 处**用 `[data-view-tab]`（`front/tests/frontend.test.mjs` 2 处 + `front/tests/source-view.test.mjs` 1 处）⇒ ⇒ **侧边栏项保留 `data-view-tab` 属性名** ⇒ ⇒ **零用例改动** |
| F7 | `VIEW_REGISTRY` 有 **8 项**（product / embedded / debug / regmem / waveform / source / terminal / memory-map）+ 1 个 fallback ⇒ ⇒ **无分组元数据** ⇒ ⇒ 分组要新加**一个**落点 |
| F8 | app 层**已有** `step` / `step10` / `continue` / `pause` / `reset` 命令（`front/app.js` 的 `case`）⇒ ⇒ 顶栏运行条**不必新增契约命令** |
| F9 | 状态源有 `pc` / `timeVirt` / `gpr`（`front/services/m10_registermemory.js` 的 `getSnapshot()`）⇒ ⇒ **没有指令退休计数** ⇒ ⇒ 原型顶栏那个「inst 1090000」**没有数据来源** ⇒ ⇒ **平台不编造**（见裁决 E） |
| F10 | 视图状态通过**窗口级** `riscv:render` 事件分发（`detail = {viewId, type, state}`）⇒ ⇒ 顶栏读状态**走事件**（与 STAGE-33 的页头加载器同一套路）⇒ ⇒ **不挂 `viewStore.subscribe`**（`reset()` 会清空订阅者 ⇒ ⇒ 会永久失联） |
| F11 | 原型的波形用 `https://fastly.jsdelivr.net/npm/echarts@5.5.0/dist/echarts.min.js` ⇒ ⇒ **外部 CDN 依赖** ⇒ ⇒ 破 ADR-6「零依赖」⇒ ⇒ 用户已拍板引入 ⇒ ⇒ 落在 v0.51 批 |
| F12 | 原型的导航分组是「**运行与调试**」（工作台概览 / 调试器 / 寄存器·内存 / 波形 / 串口终端 = 5）与「**平台**」（产品树 / 板级内存图 / 源码 = 3）⇒ ⇒ 与现有 8 个视图**一一对应** ⇒ ⇒ **不增视图、不删视图** |

### §1.3 本批**不做**

- ⛔ 视图**内部**内容形态（器件 chip / 内存比例条 / 寄存器 ABI 名与变化高亮 / 终端 TX·RX / 产品树可折叠 / 源码文件列表 / 内存 hex 查看器）⇒ ⇒ **v0.50 批**。
- ⛔ **波形图**（echarts / Canvas）⇒ ⇒ **v0.51 批**。
- ⛔ **断点 UI** ⇒ ⇒ **v0.50 批**。
- ⛔ 改**路由契约**（仍是 hash 路由、仍是 8 个视图、仍不增删命令）⇒ ⇒ **面板标题文字也不动**（`v.name` 保持原样 ⇒ ⇒ 前端门禁对页脚文案的断言零改动）。
- ⛔ 改**页头加载器的形态**（STAGE-33 的 B-6 ~ B-11 **一字不改**）⇒ ⇒ 原型那个「加载固件…」按钮形态留给 v0.50。

## §2 裁决

| 号 | 裁决 |
| --- | --- |
| A | **保留 hash 路由，只换呈现** ⇒ ⇒ 侧边栏项是 `<a href="#/...">` ⇒ ⇒ 点它就是改 `location.hash` ⇒ ⇒ `route()` / `switchView()` / `mountPanels()` **一个字不改** ⇒ ⇒ **路由契约零变更** |
| B | 侧边栏项**保留 `data-view-tab` 属性** ⇒ ⇒ `syncTabState()` **零改动** ⇒ ⇒ 前端用例**零改动** ⇒ ⇒ 导航项同时带 `aria-current="page"` 语义 |
| C | 视图的**分组**是 `VIEW_REGISTRY` 的一项元数据（`group: "run" \| "platform"`）⇒ ⇒ **分组只有一个落点** ⇒ ⇒ 侧边栏**按它渲染** ⇒ ⇒ 不另设一张分组表 |
| D | 设计令牌**集中在 `front/style.css` 的 `:root`** ⇒ ⇒ 配色 / 字体 / 圆角**只有一处** ⇒ ⇒ 不在组件里散落字面量 |
| E | 顶栏运行条显示 **PC** 与**虚拟时间** ⇒ ⇒ **不显示指令退休计数**（F9 ⇒ ⇒ 无数据来源 ⇒ ⇒ **不编造**）⇒ ⇒ 原型那个「inst」是**示意数据** |
| F | 页头加载器**形态不动** ⇒ ⇒ STAGE-33 的 B-6 ~ B-11 **全部仍然成立**、**一字不改** ⇒ ⇒ 「加载固件…」按钮形态留给 v0.50 |
| G | 视图外框改成 `.vhead`（标题 + 提示）**加** `.card` 容器 ⇒ ⇒ **内容形态**留给 v0.50 ⇒ ⇒ 本批只换**外框** |
| H | 窄屏（`< 720px`）侧边栏变**抽屉**（汉堡按钮开合）⇒ ⇒ 720px 以下侧边栏**不占宽度** ⇒ ⇒ 主区不被遮挡 |
| I | 图标用**内联 SVG** ⇒ ⇒ 零依赖 ⇒ ⇒ **不用图标字体库**、**不用图片外链** |
| J | 契约层**零升版** ⇒ ⇒ `SCHEMA_VERSION` 仍 **8** / `SIM_STATE_SCHEMA_VERSION` 仍 **2** / `PLATFORM_SCHEMA_VERSION` 仍 **1** / `PLATFORM_RULES_VERSION` 仍 **3** ⇒ ⇒ 零新 DTO / 零新命令 / 零新事件 |
| K | 顶栏的运行条按钮**复用 app 层已有命令**（F8）⇒ ⇒ **不新增**命令处理分支 ⇒ ⇒ 与 v0.48 的 `handleLoadImageCommand` **同一套路**（抽出 → 两处共用） |
