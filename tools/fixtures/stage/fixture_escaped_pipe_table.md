# 夹具 · 表格切分口径（转义竖线）

> ⚠️ **这是夹具，不是规格** ⇒ ⇒ 它**只**用来暴露「**表格怎么切**」这条约束的
> **两份落点**差异：朴素 `split("|")` ⇔ `tools/doc_check.py` 的 `split_row`。
>
> ⚠️ **判据是「差集」，不是「全绿」**：本夹具对「裁决 / 章节 / 验收 / 钉住」
> 那几项**故意不合格**（它不是任何一份真规格）⇒ ⇒ 那几项在**两份口径**下
> **逐项相同** ⇒ ⇒ 差集里**只该**剩 `[表格]` 那一类。

## §0 夹具要暴露的现象

| 现象 | 口径 | 结果 |
| --- | --- | --- |
| 单元格里有**转义竖线** `\|` | **新口径** `split_row` | **不切列** ⇒ 列数不变 ⇒ **不报** `[表格]` |
| 单元格里有**转义竖线** `\|` | **旧口径** 朴素 `split("\|")` | **误切**成两格 ⇒ 列数 ≠ 首行 ⇒ **报** `[表格]` |

## §1 口径说明

GitHub 的表格里 `\|` 是**字面竖线**（**不切列**）⇒ ⇒ 朴素 `split("|")` 把它
**误切**成一列 ⇒ ⇒ 表格列数检查**假红** ⇒ ⇒ 「表格怎么切」这条约束**必须只有
一处定义** ⇒ ⇒ 落点是 `tools/doc_check.py` 的 `split_row` ⇒ ⇒ 四个规格自检
脚本**一律 import** 它 ⇒ ⇒ **不许**在脚本里再写第二份。

## §2 跑法

```bash
python3 tools/stage14_check.py tools/fixtures/stage/fixture_escaped_pipe_table.md
```

⚠️ **新口径** ⇒ 失败集里**没有** `[表格]`；**旧口径** ⇒ 失败集里**多出**
`[表格]` 那一类 ⇒ ⇒ 两者之差 = `[表格]` ⇒ ⇒ 即为判别力。

## §3 这份夹具**故意**不合格的项

| 项 | 为什么故意 |
| --- | --- |
| 裁决 | 本夹具**不是**任何一份真规格 ⇒ 没有裁决表 ⇒ 四个脚本都会报「裁决表缺」 |
| 章节 | 四个脚本要的章节范围**不一致**（`§0~§10` 对 `§0~§11`）⇒ ⇒ 不可能同时满足 |
| 验收 | 编号组与真规格**不同** ⇒ ⇒ 与「钉住」同理 |
| 钉住 | 真规格的关键字面量**与本夹具无关** ⇒ ⇒ 同上 |

## §4 结论

「**真规格跑绿不代表口径对**」⇒ ⇒ 判别力**必须**有**专门夹具** ⇒ ⇒ 本文件
就是那个夹具。
